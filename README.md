# SAS Progress Console

Application console développée en JavaScript avec Node.js pour suivre et gérer la progression des apprenants pendant les 7 jours de formation.

## 📌 Description

SAS Progress Console permet de gérer les apprenants et de suivre leurs résultats journaliers.

L'application permet de :

- Ajouter un apprenant
- Vérifier qu'un identifiant n'existe pas déjà
- Enregistrer ou modifier un résultat journalier
- Rechercher un apprenant par son identifiant
- Rechercher un apprenant par une partie de son nom
- Calculer la progression d'un apprenant
- Classer les apprenants par niveau
- Trier les apprenants par progression
- Trier les apprenants par ordre alphabétique
- Afficher un tableau de bord global

## 🛠️ Technologies utilisées

- JavaScript
- Node.js
- Console / Terminal
